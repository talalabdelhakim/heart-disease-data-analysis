#  Heart Disease Analysis & Power BI Dashboard

##  Project Overview

This project analyzes a Heart Disease dataset to explore patterns, relationships, and factors associated with heart disease.

The project combines **Exploratory Data Analysis (EDA) using Python** with an interactive **Power BI Dashboard** to transform the raw data into meaningful insights and visualizations.

##  Objectives

* Explore and understand the dataset structure
* Clean and prepare the data for analysis
* Analyze patient demographics and health indicators
* Identify relationships between different variables and heart disease
* Create meaningful data visualizations
* Build an interactive Power BI dashboard
* Extract key insights from the data

##  Dashboard

The Power BI dashboard provides an interactive overview of the dataset, including:

* Total Patients
* Heart Disease Percentage
* Heart Disease Distribution
* Heart Disease by Gender
* Heart Disease by Chest Pain Type
* Heart Disease by Exercise-Induced Angina
* Heart Disease by ST Slope
* Age and Cholesterol Analysis

##  Key Insights

The analysis highlights several patterns in the dataset:

* Heart disease prevalence varies across different age groups.
* Exercise-induced angina shows a noticeable relationship with heart disease status.
* Heart disease prevalence differs across chest pain categories.
* Cholesterol levels vary across patients and can be explored alongside other health indicators.
* Gender-based differences can be observed in heart disease prevalence.

> **Note:** These findings describe patterns in the dataset and should not be interpreted as medical conclusions or causal relationships.
